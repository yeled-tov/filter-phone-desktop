# התקנה, שדרוג, שחזור והסרה

## התקנה

1. הורדת `FilterPhone-Desktop-Setup.exe` ואימות ה-SHA‑256 (README).
2. הרצה ואישור UAC.
3. אישור האישורים המוסברים (תעודת סינון, kill switch, Chrome בלבד). ביטול אישור
   אפשרי — אך אז ההגנה חלקית, והממשק יציג זאת.
4. ההתקנה: מתקינה את ה-MSI הרשמי של WireGuard (אם לא מותקן), מתקינה את השירות עם
   start=auto ו-restart-on-failure, רושמת את ההסכמה, ומזהה מהדורת Windows Home.
5. בחלון שנפתח: **"הצטרפות לשירות"** — טופס בארבעה שלבים כמו באפליקציה לטלפון (פרטים ← רמת
   סינון ← מה עוד לחסום ← שליחה). הבקשה מגיעה לדשבורד (טאב "בקשות", מסומנת "מחשב Windows");
   אחרי הסדרת התשלום המנהל מאשר, והמחשב מתחבר לבד תוך כחצי דקה ומפעיל את ההגנה. עד האישור
   שום דבר במחשב לא משתנה. או: **"יש לי קוד הפעלה"** — הפעלה מיידית עם קוד מהדשבורד.

ההתקנה **idempotent**: הרצה חוזרת לא יוצרת שירותים/כללים/מדיניות כפולים.

## שדרוג

**עדכון אוטומטי (ברקע):** השירות בודק לבד כל ~6 שעות אם יש גרסה חדשה בפיד העדכונים
(`update.json` ב-GitHub Releases, דרך HTTPS). כשיש — הוא מוריד את קובץ ההתקנה דרך המנהרה
המסוננת, מאמת את ה-SHA‑256 ואת חתימת ה-Authenticode של המפרסם, ומריץ אותו בשקט (שדרוג
במקום, בלי חלון ובלי שאלה למשתמש). ההסכמה, ההפעלה והנתונים נשמרים. ההתקנה עוצרת את השירות
לפני החלפת הקבצים ומפעילה אותו מחדש — בלי אתחול. (עדכון זה אינו הסרה, ולכן אינו דורש קוד הסרה.)

**חשוב:** ההתקנה האוטומטית פועלת רק כשקובץ ההתקנה חתום (מוגדר `FpUpdatePublisher` לפי תעודת
החתימה). בגרסה לא חתומה — השירות עדיין מזהה שיש גרסה חדשה ומציג זאת בחלון, אבל לא יריץ קובץ
לא מאומת כמערכת. כדי להפעיל עדכון אוטומטי מלא צריך תעודת חתימת קוד (`CODE_SIGN_PFX_BASE64`).

**שדרוג ידני:** אפשר תמיד להריץ גרסה חדשה של ההתקנה מעל קיימת — קבצים מוחלפים, השירות מתעדכן,
ההסכמה והנתונים נשמרים, בלי להסיר קודם.

## שחזור (recovery)

- **אין אינטרנט כי ה-kill switch פעיל** (נדיר): הסרת חסימת הגלישה **אינה דורשת קוד הסרה** — היא
  רק מחזירה אינטרנט (fail-open), וכל עוד השירות פעיל הוא מחזיר את הנעילה תוך שניות. ממנהל מריצים:
  ```
  "C:\Program Files\FilterPhone Desktop\FilterPhone.Service.exe" --remove-network-lock
  ```
  אתחול השירות או הרצה חוזרת של ההתקנה יחזירו את ההגנה.
- **אין אינטרנט וגם התוכנה כבר הוסרה / הקובץ לא קיים** (נעילת WFP נשארה): מריצים ממנהל את סקריפט
  השחזור `recovery/FilterPhone-Recover-Internet.ps1`. הוא מסיר את נעילת הרשת של FilterPhone ישירות
  מ-WFP דרך ה-GUIDs הקבועים, בעזרת רכיבי Windows בלבד, בלי קובץ של FilterPhone ובלי קוד:
  ```
  powershell -ExecutionPolicy Bypass -File recovery\FilterPhone-Recover-Internet.ps1
  ```
  נעילת ה-WFP קבועה (שורדת אתחול), ולכן אתחול לבדו לא מספיק — צריך את הסקריפט או את הפקודה שמעליו.
  ההסרה הרגילה של התוכנה ממילא מסירה את הנעילה **ראשונה ובלי תנאי**, כך שהסרה תקינה לא משאירה מחשב בלי אינטרנט.
- **בדיקת מצב מהיר** (מנהל): `... FilterPhone.Service.exe --status`.
- **דוח אבחון מצונזר**: מהממשק → "ייצוא דוח אבחון", או `... --diagnostics`.
- לוגים: `C:\ProgramData\FilterPhone\Logs` (SYSTEM/מנהלים בלבד, סודות מצונזרים).

## הסרה

Settings → Apps → FilterPhone Desktop → Uninstall (או Control Panel).

**במחשב שהופעל נדרש קוד הסרה.** את הקוד מפיקים בדשבורד: טאב "מחשבים" ← המחשב ← "שליטה
במחשב" ← "הפקת קוד הסרה". הקוד מתאים רק למחשב הזה, תקף 24–48 שעות, ונבדק במחשב עצמו (גם בלי
אינטרנט). תוכנת ההסרה פותחת חלון בעברית להקלדת הקוד; בלי קוד — ההסרה מתבטלת וההגנה ממשיכה.
הסרה שקטה: `unins000.exe /SILENT /REMOVALCODE=XXXXX-XXXXX`. אין צורך בקוד כשהמחשב לא הופעל,
כשהוא נמחק בדשבורד, או כשהוא עוד לא קיבל מהשרת מפתח לקודי הסרה (שרת בגרסה ישנה).

ההסרה:
1. עוצרת ומסירה את השירות.
2. מריצה `--cleanup`: מסירה **קודם** את ה-kill switch (כדי לא להשאיר בלי אינטרנט),
   ואז את שירות המנהרה, את תעודת הסינון (רק זו שהוספנו), את הגבלת הדפדפנים ומדיניות
   Chrome (משחזרת ערכים קודמים), ומוחקת סודות ומצב.
3. מוחקת את מפתח ההסכמה ברישום.

ההסרה משחזרת רק את מה שהתוכנה שינתה — בלי לגעת בהגדרות משתמש או בכללי חומת אש אחרים.
שירות WireGuard הרשמי נשאר במחשב אלא אם הוסר ידנית (הוא רכיב כללי). איפוס/התקנה
מחדש של Windows תמיד אפשריים.
